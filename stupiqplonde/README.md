# Encore 67 messenger

Локальный мессенджер на Vue 3, TypeScript, Tauri 2 и SQLite. История, пользователи,
чаты и каналы хранятся на компьютере. Светлый интерфейс объединяет панель
разделов, список разговоров и переписку; аккаунт находится внизу слева.

## Запуск

Из этой папки выполните `npm install`, затем `npm run tauri dev`.
Для работы с базой нужен запуск через Tauri. `npm run dev` запускает только фронтенд.
Миграции SQLite применяются автоматически при открытии базы.

Уже применённые SQL-миграции не редактируйте: SQLx проверяет их контрольные суммы.
Новые изменения схемы добавляйте отдельной миграцией. `.gitattributes` сохраняет
переносы строк в SQL-файлах, чтобы Git не изменял контрольные суммы.

Для старой базы с миграциями 1–9 и ошибкой контрольной суммы № 9 есть одноразовое
исправление: `node scripts/repair-channel-migration.mjs "полный путь к messenger.db"`.
Скрипт проверяет совпадение схемы и первых восьми миграций, сохраняет резервную
копию рядом с базой и исправляет только запись о контрольной сумме. При другой
схеме он прекращает работу без изменения базы. Ошибки подключения отображаются
в окне входа; кнопка «Повторить подключение» позволяет повторить запуск базы.

## Аккаунты

При запуске появляется окно входа и регистрации. Для существующих пользователей
логин — `user`, пароль — `123456`; после входа выберите нужный профиль.
Имя пользователя, старая история и участники чатов сохраняются.

Вкладка «Регистрация» создаёт новый аккаунт с собственным логином и паролем.
Пароль должен содержать минимум 6 символов. Новые аккаунты начинают с пустым
списком разговоров: создайте чат или вступите в канал по приглашению.

Нажмите на аккаунт внизу слева, чтобы изменить профиль или пароль, добавить ещё
один аккаунт, переключиться между аккаунтами, в которые уже выполнен вход,
или выйти. При закрытии приложения сессия завершается, при следующем запуске
нужно войти снова. Пароли сохраняются в виде хеша; изменённый пароль не сбрасывается
на стандартный при повторном запуске.

Для просмотра интерфейса без запуска Rust выполните `npm run preview:ui`
и откройте `http://127.0.0.1:1422/tests/ui-preview.html`.
Предпросмотр использует отдельную базу в памяти с тестовыми сообщениями;
изменения в нём не затрагивают историю приложения.

## Каналы

Нажмите «Новый канал», задайте название и, при необходимости, выберите участников.
Создатель становится владельцем и может публиковать, редактировать и удалять свои
посты, прикреплять изображения и пересылать сообщения в канал.
Создание канала и его участников выполняется одной транзакцией.
Если после сохранения канал не загрузился, нажмите «Повторить загрузку»:
приложение откроет уже созданный канал без повторного создания.
При ошибке публикации текст остаётся в поле ввода, чтобы можно было повторить отправку.

В заголовке канала владелец видит восьмизначный код приглашения.
Другой пользователь может нажать «Вступить по коду»; повторное вступление
открывает существующий канал без дублирования участников.
Подписчики читают публикации, ставят и снимают реакции и оставляют комментарии.
Код работает в той же локальной базе приложения.

## Проверки

- `npm run build` — проверка TypeScript и сборка фронтенда.
- `npm test` — проверки миграций, приглашений, прав публикации, пересылки,
  реакций и комментариев на SQLite в памяти, а также состояний Vue при ошибках
  создания и публикации, входа, регистрации, смены пароля и переключения аккаунтов.
  Требуется Node.js 22.18+ с поддержкой
  `node:sqlite` и выполнения TypeScript.
- `cargo test --manifest-path src-tauri/Cargo.toml --lib` — проверка транзакционного
  создания канала, ролей, повторяющихся участников и отката при ошибке.
